# Verifying Suricata Logs

## Objective

The purpose of this step was to verify that Suricata was successfully generating logs before forwarding them to Wazuh.

---

## Log Location

Suricata stores its logs in:

```bash
/var/log/suricata/eve.json
```

---

## Verification

I confirmed that the log file existed and contained events by running:

```bash
sudo tail /var/log/suricata/eve.json
```

The command displayed JSON-formatted events generated by Suricata, confirming that the IDS was actively logging network activity.

# Verifying Wazuh Logs

## Objective

The purpose of this step was to verify that Wazuh was successfully reading the Suricata logs after configuring the integration.

---

## Verification

After updating the Wazuh configuration and restarting the Wazuh service, I verified that the manager was processing the Suricata log file.

I used the following command:

```bash
sudo grep eve.json /var/ossec/logs/ossec.log
```

---

## Expected Output

The output should contain a message similar to:

```text
INFO: (1950): Analyzing file: '/var/log/suricata/eve.json'
```

This confirms that Wazuh is monitoring the Suricata log file.

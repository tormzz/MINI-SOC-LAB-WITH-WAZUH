# Investigating ICMP Alerts

## Objective

The purpose of this exercise was to investigate a network security alert generated by Suricata and review the event details in the Wazuh Dashboard.

---

## Lab Environment

| Component | Description |
|----------|-------------|
| Attacking Machine | Kali Linux |
| Target System | Ubuntu Server (Wazuh Agent + Suricata) |
| SIEM Server | Ubuntu Server (Wazuh Manager) |
| IDS | Suricata |
| Monitoring Dashboard | Wazuh Dashboard |
---

## Generating the Alert

I used my Kali Linux machine to perform an Nmap scan against the monitored Ubuntu endpoint running the Wazuh agent and Suricata.

The alert was forwarded to the Wazuh Manager and appeared in the Threat Hunting dashboard.

---

## Investigation

I searched for the Suricata alert in the Wazuh Dashboard and opened the event details.

The alert identified the traffic as:

 - SURICATA ICMPv4 unknown code

The event also included details such as:

- Source IP
- Destination IP
- Alert severity
- Alert signature
- Timestamp

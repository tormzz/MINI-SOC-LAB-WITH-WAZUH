# Integrating Suricata with Wazuh

## Objective

I configured Wazuh to monitor Suricata logs so that network events generated by Suricata could be collected and analyzed by Wazuh.

---

## Environment

- Ubuntu Server 26.04
- Wazuh Agent 4.14.6
- Suricata IDS

---

## Configuration

I opened the Wazuh agent configuration file:

```bash
sudo nano /var/ossec/etc/ossec.conf
```

Inside the `<ossec_config>` section, I added the following configuration to tell Wazuh where to find the Suricata log file.

```xml
<localfile>
  <log_format>json</log_format>
  <location>/var/log/suricata/eve.json</location>
</localfile>
```

After saving the changes, I restarted the Wazuh agent so the new configuration would take effect.

```bash
sudo /var/ossec/bin/wazuh-control restart
```

---

## Verification

To make sure the configuration was added correctly, I checked the Wazuh configuration file.

```bash
sudo grep eve.json /var/ossec/etc/ossec.conf
```

The command returned the `eve.json` entry, confirming that Wazuh had been configured to monitor the Suricata log.

Next, I confirmed that Wazuh was actively reading the log file.

```bash
sudo grep eve.json /var/ossec/logs/ossec.log
```

The output showed:

```text
INFO: Analyzing file: '/var/log/suricata/eve.json'
```

This confirmed that the integration was successful and that Wazuh was monitoring Suricata events.

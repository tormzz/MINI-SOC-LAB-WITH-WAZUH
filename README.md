# SOC Home Lab – Wazuh & Suricata

## Overview

This project documents the design and implementation of a Security Operations Center (SOC) home lab using Wazuh and Suricata.

The objective of the lab is to simulate the workflow of a SOC analyst by collecting, monitoring and investigating security events generated from a Linux endpoint.

The project demonstrates:

- Wazuh Agent deployment
- Suricata IDS deployment
- Log collection
- Event monitoring
- Security investigations
- Incident documentation
- Troubleshooting

---

## Lab Environment

| Component | Technology |
